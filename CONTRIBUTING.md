# Contributing

Vork is one engineer's working kit, published as it is used. It changes when the author's own practice changes, and each change ships as a tagged release.

Take what you need. The license is MIT: fork it, lift a piece of it, or use it as the reference for a kit of your own. There is no process to follow and nothing to send back.

An issue is welcome for anything that is plainly wrong: a step in the README that fails as written, a command whose output contradicts its spec, a leak of something that should not be here. Say what you ran, what you saw and what you expected; the correction lands in a release and the issue closes with it.

Pull requests are read, and a small correction may be taken; a change to how the kit works is a different matter, since the kit follows one practice and that practice is the author's. Open an issue first for anything beyond a fix, and expect a plain answer either way.

Release 1, tag `v2026.10.13`, is a frozen record of a retired framework and takes no changes at all.
